# Create grid map art — トップビュー・マップチップ・NPC

## 事前確認
- `AGENTS.md`、`../asset-design/SKILL.md`、`docs/REPOSITORY_POLICY.md`、採用素材台帳、関連画像の現物を読む。
- 第1作『鬼哭の花結び』の**格子探索マップ**は1セル32×32px基準。続編や非格子の戦闘・イベント画像へ無条件に適用しない。
- 新リポジトリに採用素材が存在しない間は旧作品のグラフィックを勝手に採用したことにしない。
- 描画画像、セル座標、見た目の占有サイズ、足元アンカー、物理判定、遮蔽を別データにする。

## 村・地形・マップチップ
1. マップ列×行、視点、移動（原則上下左右のマス単位）、入口/出口、必要通路、地形接続とレイヤーを先に確定。
2. 入口・橋・建物の周辺を含む経路を確保。依頼されていない面積や建物を勝手に増やさない。
3. 地面や道路は既存タイルを最優先。追加が必要な場合は中心・上下左右辺・内外角・直線・分岐の不足役割だけ制作。角だけを増やして直線を欠落させない。
4. 3×3反復と接続を検査。タイルと地形の通行フラグは分離し、配置は`data/maps/`に保存。画像ピクセルから判定を導かない。
5. 建物・木・NPCは実RGBA、接地、占有セル、遮蔽を明示。ゲーム本体の実キャラ・実レンダラーで表示確認する。
6. 一枚絵を背景として直接使う方式と独立マップチップへ切り出す方式は区別。一枚絵の自動レイヤー分解で大量制作できると仮定しない。

## 鬼灯村の建物と歩行検査
- 建物の新作・差し替え、軒下の遮蔽、裏回り、入口、iPhone用の検査ページを扱うときは、[鬼灯村の建物制作・検査手順](references/hozuki-village-buildings.md)を最初に読む。
- 建物1棟の透過画像を原本とし、手前に重ねる軒だけを同じ原本から切り出す。足元の当たり判定、描画順を切り替える境界、入口の起動範囲はそれぞれ設定する。
- 裏から当たり判定に接したときも緋月の頭が一部見える位置に調整する。建物ごとに緋月の歩行フレームで検査し、iPhone Safariで確認できる版付きのPages URLを示す。

## NPC・キャラクター
- 緋月に関するグラフィック制作は必ず `../hizuki-character/SKILL.md` と `docs/characters/HIZUKI_CANON.md` を先に確認する。リポジトリ内の採用画像を基準にし、昔の設定画や続編の姿へ置換しない。
1. 採用外見の正面画像を特定し、頭身・顔・輪郭・色・装束を実等倍で確認する。
2. 正面が承認されたら必要な向きや歩行へ展開。高さ・足元・色・アクセサリー・共通切り抜き座標を検査。
3. 左右反転はデザイン上対称であることを確認した場合だけ使用し、手前/奥の腕・脚も検査。
4. 大きな画像の単純縮小や自動減色だけで「本物の32pxドット絵」と呼ばない。
5. 登録・採用後、実ゲーム内でマスずれ、足滑り、遮蔽、切り抜き混入を検査する。

## 完了条件
採用承認、素材検査、タイル接続、実歩行、GitHub反映、Pages配信、iPhone Safari実機を別の確認事項とする。不合格のたびに自動再生成せず、まず原因と加工可能性を調べる。
