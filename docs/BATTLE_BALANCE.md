# 『鬼哭の花結び』戦闘バランス設計・復旧記録

2026-11-13。正本リポジトリ `HiHoSir/kikokuno-hanamusubi`。B式v2のヒヅキ成長・計算は確定済み。敵・装備・分布・販売はすべて**一次案**。ゲームにまだ存在しない地域・店・装備を実装済みと呼ばない。

## 確定済み
- 段1：体力26／技12／攻9／守6／はやさ9。段アップは体力+8、技+1.3、攻+2.6、守+1.6、はやさ+2。総量を四捨五入。
- 物理ダメージ `floor(攻/2−守/4)`、乱数±1/16、最低保証は攻の約1割。A式の攻−守方式は不採用。
- 上限99、ラスボス想定段40。次段までの心 `round(80×段^1.35)`。段アップで体と技が全回復。
- 装備合計ボーナス：T0（攻0・守0）／T1（20・14）／T2（42・30）／T3（64・46）／T4（88・64）／T5（114・84）／T6（140・104）。ゲーム内の武器・防具枠はこの別途設計。
- 第一覚醒：体力+20、攻+8。第二：守+8、はやさ+6。第三：上昇値未定。各覚醒は**物語イベントで発生**、段に固定しない。
- 敗北時：所持両25%を失い最後に訪れた町へ帰還。現在実装済みの町は鬼灯村だけ。

数値原本：`data/characters/hizuki-status.json`。プログラムの成長値と一致するよう検査を設ける。

## 現行本編で調整済みの序盤（2026-11-13）

- 実装対象は **フィールドの第一ルート「鬼灯村 → 天妖の社」だけ**。地形原本は `data/maps/field/terrain.js` の `referenceComposition.roads[0]`。フィールド表示に使われる移動座標から、実在するルートのどの区間にいるかを判定する。
- ルートの前半60%は「鬼灯村の外れ」、後半40%は「天妖の社への道」。道路から4セル超離れた場合は前半の安全側を採用する。現在未接続の海・森・滝・九尾方面に強敵を仮配置しない。
- 出現比率：外れは野の小鬼1体55%／化け狸2体45%。社への道は野の小鬼1体20%／鬼火1体45%／化け狸2体35%。**既存承認画像3種類のみ**。

## 敵2体・装備・店の未決
- 敵の複数出現は1〜2体。単独型は1体、複数型は最大2体。複数型の攻撃は1体の半分程度とし、初期案では強敵と混合しない。
- T7（武器+166、防具+124）／T8（+192、+144）は旧作前提の**案にすぎない**。導入の可否・販売時期は未決。

- 術12候補は `docs/SPELL_CANDIDATES.md` に保存。術の深掘りは保留。
