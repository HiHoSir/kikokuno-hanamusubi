# 『鬼哭の花結び』戦闘システム（本編・第1段階）

## 採用規格
- 主人公は緋月1人。第2作向けの4人パーティ案は適用しない。
- ゲームの本編親ページは `src/game/index.html` のまま維持。戦闘は `src/game/battle/` 内の描画シーンとして差し替え、BGMは親 `src/game/navigation/game-shell.mjs` が管理。
- 戦闘開始: フィールドで歩行完了を9〜13回繰り返すと通常戦闘。村と社の接触・はしご上では発動しない。現段階ではランダム敵3種類のループで、希少敵・ボスは呼び出さない。
- フィールド歩行位置は `sessionStorage` `kikokuno-hanamusubi-battle-field-return` へ保存。勝利と逃走で同じ位置に帰還、敗北では体力・術力を半分程度回復させ村の南口へ戻す。フィールド帰還直後に再エンカウントしない。
- 戦闘中の1人分の状態は `localStorage` `kikokuno-hanamusubi-battle-player`。レベル、HP、術力、銭、経験値、薬草と勝利数を保存。第1章の進行キーは変更しない。既存のフィールド座標保存ロジックと混同しない。

## 実行画面
- `src/game/battle/index.html` + `battle.css` + `walk.mjs` が実際の本編画面。戦闘操作を単独の検査HTMLに隔離しない。
- 敵素材は現リポジトリに移行済みの承認11体を再利用。今使用する通常敵は `assets/enemies/{field-oni,tanuki,onibi}.png` の3種。全画像の元出典は `assets/manifest.json` を参照。既存画像を加工・複製・再生成しない。
- 緋月の戦闘ポーズは `assets/characters/hizuki/battle/` の6画像（待機・物理攻撃・術・被弾・防御・勝利）。フィールド歩行スプライトは流用しない。
- コマンドは左に「たたかう／術／道具／防御／にげる」、右に緋月のHP・術力・薬草・銭を表示。上下左右キーとA/Bも既存共通コントローラーに対応。
- 初回接敵は白いフラッシュ、減彩、筆文字「接敵」の短い演出。BGMは `assets/audio/bgm/battle.ogg`、SEは `assets/audio/se/battle-encounter.ogg` を使用。iPhoneの許可・消音状態を尊重する。
- 初回コマンドは約1秒の接敵演出後に解放。勝利・逃走・敗北後は表示したボタンまたはAでゲーム内の遷移を行う。

## 1人分のターン処理（`rules.mjs`）
- たたかう: 通常物理ダメージ、防御による軽減あり。
- 術: 花焔（MP4、敵へ固定基礎＋振れ幅の攻撃）、癒し（MP3、緋月のHP回復）。術力不足や体力満タンの状態では敵の手番へ進まない。
- 道具: 薬草（HP26まで回復、使用時だけ1個消費）。所持なしや満タンでは敵の手番へ進まない。
- 防御: そのターンに受けるダメージを約半減。
- にげる: 75%で逃走成功。失敗すると敵の手番。
- 勝利時は経験値・銭・勝利数を加算、規定経験値でレベルアップ。HPが0になれば敗北。このステージでは敵1体・緋月1人に固定。
