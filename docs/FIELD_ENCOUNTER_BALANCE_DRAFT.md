# 通常敵の地域別分布と戦闘バランス

[敵分布マップ](https://hihosir.github.io/kikokuno-hanamusubi/previews/field-exploration/?view=enemies)に出現する区間、編成、比率、1体ごとの能力と報酬を表示する。

| 天妖の社への道 | 野の小鬼20%、鬼火45%、化け狸2体35% | 接続済み |

| 九尾の祠への参道 | 妖狐100% | フィールドで接続済み |

橋の上、はしごの移動中と入口の接触マスは安全。岩守の鬼と影九尾は固定戦枠。野の小鬼・化け狸・鬼火は序盤の地域で出る。紅葉木霊・藍糸蜘蛛は取り下げた。

通常遭遇の正本は `data/maps/field/encounter-pools.mjs`。能力と報酬の正本は `data/maps/field/regional-enemies.mjs`。洞窟の候補と尾根の未採用2体は `data/maps/field/encounter-balance-draft.mjs` に試算値を置く。数値は `node tools/audit-field-encounters.mjs` で検査できる。試戦は各地域で全快・所定の装備から開始し、本編の保存を使わない。

分布マップの試戦では単体の能力と報酬を確認できる。被ダメージは固有行動を加える前の値。橋の上は安全区間とし、橋灯りの候補地点は北岸の石畳に置く。

追加6体の戦闘絵はユーザー確認済みのドット絵を採用した。分布マップの丸印は地上5体の出現地を示す。晶殻ヤドカリは山越えの洞窟内の結晶帯に割り当てる。6体とも単体で試戦できる。本編の初期設定は次節に記載。
