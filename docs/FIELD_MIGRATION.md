# フィールドの移行元

移行元は `HiHoSir/yaksha-hanamusubi` の本編 β16.1.93、コミット [`26136fe`](https://github.com/HiHoSir/yaksha-hanamusubi/tree/26136fef4e73bcea60a73edf4e02cd252b3976d0)。歩行検査の入口は `src/field/index.html`。

| 対象 | 移行した内容 |
| --- | --- |
| 地形 | 80×80マス、1マス32px。旧 `js/field-terrain.js` を `data/maps/field/terrain.js` にコピー。高低差、海岸、橋・梯子、ランドマーク、配置物、通行・進入セルの計算も移行。 |
| 描画 | 遠近投影、画面上部の地平線と霞、地形と物体の前後順、カメラ追従、水面・滝のコマを従来のレンダラーで描く。論理キャンバス768×768、投影1.4、描画時にY方向へ32pxのオフセットと1.2倍の変換を使う。 |
| 緋月 | 旧本編と同じSDシートを台帳から使用。向き別の立ちコマで全歩行コマの基準位置をそろえ、投影中心と影を旧版に合わせる。 |
| 画像 | 台帳にある同一バイトの33点を再利用。描画コードが読み込む残りの14点をコピーし、元のパスとコミットを台帳に登録。 |
| 鬼灯村 | 公開版の村の南口と、旧フィールドの村入口セルを接続。フィールドへ戻ると、入口に隣接する通行可能セルから始まる。 |

`src/field` の旧描画モジュールは、画像参照を新リポジトリの台帳のパスへつなぎ直している。`runtime.mjs` と `walk.mjs` は描画、入力、村への移動を接続する。その他の地点はフィールド内の配置・判定までを移行範囲とする。
