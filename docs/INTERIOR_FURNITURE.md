# 鬼灯村・室内家具の制作契約（現行仕様）

対象：第1作『鬼哭の花結び』・`HiHoSir/kikokuno-hanamusubi`。旧 `yaksha-hanamusubi` で検証した「原画の外形 → 実ドット絵化 → アトラス → 足元検査」の工程を**技法としてのみ**参考にし、旧レポジトリの採用画像はコピーしない。

## 改修の理由

2026年11月17日までの家具はPythonで長方形・直線を重ねて直接描かれ、相対寸法、木部の厚み、布製品の柔らかさ、金物の立体感を十分に表せていなかった。4px格子であることと、SFC後期の画風であることは同義ではない。キャラ80×112px（実際の不透明高はそれより小さい）を比較尺度にし、箪笥、布団、囲炉裏、武器棚、帳場に固有の形を与える。

## 素材契約

- デザイン：和風RPGの3/4見下ろし。木材は暖色、金具は暗い鉄色、布は藍・朱色を主体とし、輪郭はほぼ黒。パレットを単純化し、過度の微細テクスチャを抑える。
- 1論理画素=2ワールドpx。元原画をゲーム画像としてそのまま縮小しない。論理グリッドで外周1pxの輪郭を確定したマスターを保管し、ゲーム画像へは最近傍2倍のみ使用する。
- 原本：`source-assets/village/interiors/furniture-master.png`（448×352）。出力：`assets/village/interiors/furniture.png`（896×704）。
- 再現：`python tools/build-interior-furniture.py`。一致検証：`python tools/build-interior-furniture.py --check`。
- 全16種の画像範囲、設置範囲は `src/game/interiors/rooms.mjs` に一元化。人物・家具の実画像は描画時には常に原寸で扱う。カメラだけが画面全体を拡大縮小する。
- 家具の透明画素を含む矩形と、床で占める範囲を分離する。戸棚・棚の当たり判定は下端の脚元、囲炉裏と布団は床に接する範囲を基準とする。既存のNPCの会話アンカーと発見物の位置は新しい判定範囲から計算する。
- 画材・造形の候補であることとユーザーの最終採用は別。比較画像だけで本編の品質保証やiPhone実機検査の代わりにしない。

## 検査順

1. 家具16種の透明・形・2pxピッチ・相対比を一覧で目視比較。布団が立ち物に見えないこと、棚とカウンターの向き・比率が正しいことを確かめる。
2. `npm test` および`python tools/build-interior-furniture.py --check`で寸法、足元、生成一致を確認。
3. **実際の本編**で緋月と店番を並べて茶店・宿・兵具屋・民家を周回し、家具の前後・接地影・隠しアイテムの「？」・会話・出入りを確認。
4. GitHub Actions、Pagesの配信、iPhone Safariの横画面操作は個別に検査。実施していないものは合格扱いにしない。

## 出典と経緯

このマスターの元画像は本作のために新しく生成した16種の和家具を含む透過スプライトシートであり、既存ゲーム画像や参照作品の画素を転用したものではない。大きな原画の透明外形を切り分け、用途別の寸法へ規格化し、48色程度へ整理、外側1論理画素の暗い輪郭を付けて実寸の2pxピッチで画素を確定した。描画は一つのアトラスから切り出し、各オブジェクトについて実行時の拡縮を行わない。

## 2026-11-17 室内配置調整

家具の見た目を2pxアトラスに更新したあとも、旧寸法前提の配置を残さないこと。配置の正本は `src/game/interiors/rooms.mjs` の各 `furniture` 配列であり、別の重複マップを作らない。

- 茶店：卓2台を畳上で対称に配置し、4枚の座布団を左右の席として置く。中央の通路を残す。
- 物販店：棚を奥壁へ揃え、帳場を中央、荷物と箪笥を左右へ退けて接客動線を確保。
- 宿：布団3組を客間に等間隔で敷き、帳場付近へ待合用座布団を移動。下駄箱は床南端の範囲内へ戻す。仕切りの両端から奥に回れる。
- 兵具屋：奥壁の武器棚・箪笥と、手前の帳場が画像上で重ならないよう帳場を南側へ移動。
- 農家：かまどを土間内に納め、囲炉裏と座布団の座る位置を合わせる。
- 家族の民家：ちゃぶ台の両脇に座布団を配置。布団と箪笥は客席から離す。
- 仕事場付き民家：作業台・材料・商品棚を西側にまとめ、東側の寝具・箪笥と区切る。

家具の描画倍率・足元の当たり判定・住人・隠しアイテムIDは変更しない。各室の画像矩形の非重複、床端と出入口、8px歩行判定付き到達性、店番への会話可能位置および箪笥の調査可能位置を `tests/interior-furniture-layout.test.mjs` で検証する。イメージは実ゲーム表示の確認の代わりにしない。iPhone Safari実機は別途検査する。

## 壁に接する家具の座標系とサイズ再検討

以前の「家具同士が重ならなければ合格」という配置基準は不十分だった。奥壁の床との境界が Y=128 にあるのに、壁際の棚や箪笥は独立Y値で配置され、空中に浮いて見える原因になっていた。

- `src/game/interiors/room-geometry.mjs` が奥壁床境界128、家具の接地開始144、左右壁内側44、玄関側の下端位置を定義。
- 部屋の `furniture` 配置は Y に `back-wall`、X に `left-wall` / `right-wall`、Y に `front-wall` を指定可能。描画と衝突で使う座標は `resolveFurniturePlacement` で一元算出。
- 棚・箪笥・武器棚・棚際の荷物・壁付けかまどは、実際の `foot` と壁の接地線で位置を決定。帳場・机・布団・囲炉裏は独立して配置。
- 箪笥は80×112pxの緋月キャラ枠との比較で過大だったため、原本の2px論理格子で輪郭・細部を保って120×108pxに修正。描画時に個別の倍率は適用しない。
- 7室の家具矩形の非重複、8pxの通行半径を考慮した到達性、住人会話・隠しアイテムの接近、壁アンカーの不変条件を回帰テストに追加。

本編のブラウザ実表示とiPhone Safariの実機検査は、自動テストおよび簡易プレビューと別途実施する。

## 室内の生活演出・建物退出時の向き

- 茶店の茶器には湯気、農家の囲炉裏・茶店のかまどには小さな炎と煙を追加する。追加PNGを量産せず、`src/game/interiors/life-effects.mjs` で家具ローカル座標に発生源を定義し、2px単位の有限フレームで表現する。
- 演出は既存家具の原寸描画直後に重ね、部屋内の深度ソートと同じ扱いにする。家具が移動しても演出だけ元の場所に残らない。当たり判定とBGMには影響を与えない。
- 独立したアニメーションループを作らず、室内の既存RAFの時間を利用する。OSの `prefers-reduced-motion` では演出フレームを固定。
- `villageArrivalFacing` は室内から帰還した建物IDの場合だけ正面（行0）を返す。セーブデータの復元や住人へのフォーカスは元の方角を維持し、建物帰還時は保存座標による上書きをしない。
- 本編のブラウザ表示とiPhone実機表示は自動テストとは別に検証する。

## かまどの静止湯気除去と動的湯気

- 2026-11-17改修：かまど素材の上部に元から描かれた白い湯気224論理画素を透明化。鍋・蓋・かまど本体・火口と、同じアトラスのほか15種は変更しない。ピクセル単位の除去であり、AIによる家具全体の描き直しではない。
- 元画像の正本 `source-assets/village/interiors/furniture-master.png` とゲーム用 `assets/village/interiors/furniture.png` を同時更新。アトラスは既存の `python tools/build-interior-furniture.py` で2倍最近傍再生成でき、`--check` で一致確認する。
- `src/game/interiors/life-effects.mjs` の `kitchen` は鍋の上から `steam` を動的に発生させる（火口の炎も継続）。静止した湯気を再度PNGに描き込まない。
- 家具の外形、表示サイズ、接地範囲、配置・通行判定は不変更。Safariが旧画像をキャッシュしないように版を更新。
- かまどの静止湯気領域の透明・鍋の残存・アニメーション発生位置を自動テストで確認。本編実機表示は別途確認する。

## かまどの完全差し替え（2026-11-17）

前回は静止湯気をピクセル単位で消したため、鍋の輪郭の一部まで欠けた。今回は既存のかまど画像を継ぎ足して直すのではなく、本作向けに作成済みのかまど原画をほかの家具に合わせて**素材化して交換**した。

- 外部向けの新たな画像生成は行わず、既存候補からかまどと臼の構成を採用。2px単位の輪郭と48色のパレットに整理し、かまど枠の論理寸法74×72pxに収め、既存家具アトラスの `kitchen` スロット（148×144px）だけ差し替えた。
- 元画像の編集可能な正本は `source-assets/village/interiors/furniture-master.png`。ゲーム用の `assets/village/interiors/furniture.png` はこの論理原本を**最近傍2倍**に拡大したもの。ほかの家具15種の画素は変更なし。
- 差し替えは描画時に個別拡大縮小せず、壁寄せ・当たり判定 `[8,74,132,66]` ・設置位置をすべて維持。
- 生成済みの新しい画像には静止した湯気を描き込まない。鍋の上からの動的な湯気は `src/game/interiors/life-effects.mjs` のエミッタ（`kitchen`）をY=28へ合わせ、火口は既存の動く炎を維持。
- 画像の透明な余白、鍋の持ち手、蓋、かまど本体、火口、臼の欠け、アトラスの2px再生成一致、動的湯気の位置を自動検査で確認する。キャッシュキーも更新し、旧版PNGの残留を防ぐ。
- ソースの意味する完成の度合いと、iPhone Safariでの実機レビューは別。実機では茶店・農家のかまどの欠け、炎の位置、湯気の見え方を確認する。


## かまどと既存家具の画風を合わせる（2026-11-18）

以前のかまどは2px格子・48色でも、ほかの家具と比べて石の斑点状ハイライトと木の黄色い彩度が強かった。既存の原本を加工し、囲炉裏の石材色・陳列棚の木材色を参照して陰影を再整理。小さな斑点を抑えて、面ごとに色のまとまりを付け、黒い外輪郭を維持する。原寸74×72論理px／148×144ゲームpx、47色。静止湯気なし。輪郭透過・家具の足元当たり判定・配置・動的な炎と湯気の位置は維持。ほか15家具の画素は変更しない。透明部を含めた残りのマスター画素をSHA-256で固定し、実画面・実機検査とは区別する。
