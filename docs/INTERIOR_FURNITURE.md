# 鬼灯村・室内家具の制作契約（改修候補）

対象：第1作『鬼哭の花結び』・`HiHoSir/kikokuno-hanamusubi`。旧 `yaksha-hanamusubi` で検証した「原画の外形 → 実ドット絵化 → アトラス → 足元検査」の工程を**技法としてのみ**参考にし、旧レポジトリの採用画像はコピーしない。

## 改修の理由

2026年11月17日までの家具はPythonで長方形・直線を重ねて直接描かれ、相対寸法、木部の厚み、布製品の柔らかさ、金物の立体感を十分に表せていなかった。4px格子であることと、SFC後期の画風であることは同義ではない。キャラ80×112px（実際の不透明高はそれより小さい）を比較尺度にし、箪笥、布団、囲炉裏、武器棚、帳場に固有の形を与える。

## 素材契約

- デザイン：和風RPGの3/4見下ろし。木材は暖色、金具は暗い鉄色、布は藍・朱色を主体とし、輪郭はほぼ黒。パレットを単純化し、過度の微細テクスチャを抑える。
- 1論理画素=2ワールドpx。元原画をゲーム画像としてそのまま縮小しない。論理グリッドで外周1pxの輪郭を確定したマスターを保管し、ゲーム画像へは最近傍2倍のみ使用する。
- 原本：`source-assets/village/interiors/furniture-master.png`（448×352）。出力：`assets/village/interiors/furniture.png`（896×704）。
- 再現：`python tools/build-interior-furniture.py`。一致検証：`python tools/build-interior-furniture.py --check`。
- 全16種の画像範囲、設置範囲は `src/game/interiors/rooms.mjs` に一元化。人物・家具の実画像は描画時には常に原寸で扱う。カメラだけが画面全体を拡大縮小する。
- 家具の透明画素を含む矩形と、床で占める範囲を分離する。戸棚・棚の当たり判定は下端の脚元、囲炉裏と布団は床に接する範囲を基準とする。既存のNPCの会話アンカーと発見物の位置は新しい判定範囲から計算する。
- 画材・造形の候補であることとユーザーの最終採用は別。比較画像だけで本編の品質保証やiPhone実機検査の代わりにしない。

## 検査順

1. 家具16種の透明・形・2pxピッチ・相対比を一覧で目視比較。布団が立ち物に見えないこと、棚とカウンターの向き・比率が正しいことを確かめる。
2. `npm test` および`python tools/build-interior-furniture.py --check`で寸法、足元、生成一致を確認。
3. **実際の本編**で緋月と店番を並べて茶店・宿・兵具屋・民家を周回し、家具の前後・接地影・隠しアイテムの「？」・会話・出入りを確認。
4. GitHub Actions、Pagesの配信、iPhone Safariの横画面操作は個別に検査。実施していないものは合格扱いにしない。

## 出典と経緯

このマスターの元画像は本作のために新しく生成した16種の和家具を含む透過スプライトシートであり、既存ゲーム画像や参照作品の画素を転用したものではない。大きな原画の透明外形を切り分け、用途別の寸法へ規格化し、48色程度へ整理、外側1論理画素の暗い輪郭を付けて実寸の2pxピッチで画素を確定した。描画は一つのアトラスから切り出し、各オブジェクトについて実行時の拡縮を行わない。

## 2026-11-17 室内配置調整

家具の見た目を2pxアトラスに更新したあとも、旧寸法前提の配置を残さないこと。配置の正本は `src/game/interiors/rooms.mjs` の各 `furniture` 配列であり、別の重複マップを作らない。

- 茶店：卓2台を畳上で対称に配置し、4枚の座布団を左右の席として置く。中央の通路を残す。
- 物販店：棚を奥壁へ揃え、帳場を中央、荷物と箪笥を左右へ退けて接客動線を確保。
- 宿：布団3組を客間に等間隔で敷き、帳場付近へ待合用座布団を移動。下駄箱は床南端の範囲内へ戻す。仕切りの両端から奥に回れる。
- 兵具屋：奥壁の武器棚・箪笥と、手前の帳場が画像上で重ならないよう帳場を南側へ移動。
- 農家：かまどを土間内に納め、囲炉裏と座布団の座る位置を合わせる。
- 家族の民家：ちゃぶ台の両脇に座布団を配置。布団と箪笥は客席から離す。
- 仕事場付き民家：作業台・材料・商品棚を西側にまとめ、東側の寝具・箪笥と区切る。

家具の描画倍率・足元の当たり判定・住人・隠しアイテムIDは変更しない。各室の画像矩形の非重複、床端と出入口、8px歩行判定付き到達性、店番への会話可能位置および箪笥の調査可能位置を `tests/interior-furniture-layout.test.mjs` で検証する。イメージは実ゲーム表示の確認の代わりにしない。iPhone Safari実機は別途検査する。
