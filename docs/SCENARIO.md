# 鬼哭の花結び シナリオ

第1章『花の声が消える里』改稿。オープニングと第1章の会話をつなぐ台本。新リポジトリのゲーム進行には未接続。

## オープニング

人と鬼が争っていた昔、両者が交わした契りが憎しみを鎮め、ふたたび花が咲いた。時は流れ、鬼灯村では緋月が橋へ向かうさとこと挨拶を交わす。翌朝、いつもの鐘が鳴らない。村の老人は家への道を、お澄は昨日の約束を思い出せず、緋月は異変を調べることを決める。

旧ムービーの語りは「その契りが憎しみを鎮め、ふたたび花が咲いたという。」。本編では、昔の人と鬼の契りをこの語りと同じ呼び方で受ける。ムービーの直後は鬼灯村から始まり、里長に話しかけると最初のイベントが進む。

## 花結び

鬼灯村には、大切な約束をしたときに、結び札に花の形の結び目を作る風習がある。里の人はこれを「花結び」と呼ぶ。約束にまつわる縁が忘れられると、札の糸に途切れが現れる。

緋月は、鐘の異変をきっかけに、人々が忘れた約束の跡をたどる。相手を思い出せなくても浜で待ち続ける潮平に出会い、最後には緋月自身も、約束を交わした相手を探すために踏み出す。

## 第1章『花の声が消える里』

### 1. 鬼灯村 — 里長

- 里長「緋月、今朝から里の鐘が鳴らんのじゃ。昨日まであった道のことさえ、誰も覚えておらん。」
- 里長「お澄は『見知らぬ地蔵に挨拶した』と言うが、あの地蔵は昔からあったはず……。」
- 里長「この結び札を預ける。里では大事な約束をしたとき、こうして糸を花の形に結ぶ。花結びじゃ。見てみい。今朝から、その糸が一本切れておる。」
- 緋月「鐘が鳴らないだけなら直せばいいと思ったけど……みんなの記憶まで変なのね。」
- 里長「天妖の社の白妙なら、札のことが分かるかもしれん。」
- 緋月「分かった、行ってくる！」

結び札を預かり、湖を左に見て北の草原へ。天妖の社で白妙を探す。

### 2. 天妖の社 — 白妙

- 白妙「この糸の切れ方は、誰かとの縁を忘れたときに現れる印です。」
- 白妙「昔、人と鬼が交わした契りは憎しみを鎮めました。そのとき、大切な約束まで忘れた者がいたと伝わっています。」
- 緋月「大切なものを忘れて平和になるなんて、変な話ね。」
- 白妙「今朝の異変とつながっているかは、まだ分かりません。海の入り江で、潮平という漁師が光る花びらを拾ったそうです。まずは話を聞いてみてください。」

結び札が淡く光る。川沿いの道から海の入り江へ。

### 3. 海の入り江 — 潮平

- 潮平「昨夜の潮は妙だった。波が引いたあと、見たこともない花がひとひら残っていてな。」
- 潮平「これを見ると、昔ここで誰かを待っていた気がする。誰だったかは思い出せないが……。」
- 緋月「待っていたことは覚えてるんだね。花びら、預かってもいい？　手がかりを探してみる。」
- 潮平「持っていきな。忘れの森の方へ光が伸びている。俺はここで、帰る人を待つよ。」

潮花の花びらを受け取り、浜から北東の忘れの森へ。

### 4. 忘れの森 — 旅の薬師

- 旅の薬師「この森の木々は、人が忘れた言葉を代わりに覚えているんです。耳を澄ますと聞こえるでしょう。」
- 緋月「……『忘れても、迎えに行く』？　誰の声だろう。」
- 旅の薬師「花びらに宿った記憶でしょう。龍神の滝の水鏡に映せば、その景色が見えるはずです。」
- 旅の薬師「ただし、思い出せば必ず幸せになるとは限りません。それでも進みますか？」
- 緋月「うん。知らないまま誰かを置いていくのは、もっと嫌だから。」

潮花の光を追い、北の龍神の滝へ。

### 5. 龍神の滝 — 滝童

- 滝童「お姉ちゃん、花びらを水にかざして！　水鏡は、忘れられた景色を映すんだ。」
- 水面に、九本の尾を持つ白い影と、手を取り合う二人の姿が揺れる。
- 緋月「この景色……知らないはずなのに、胸が苦しい。」
- 滝童「西の九尾の祠へ行けば、白狐の使いに会えるよ。だけど、見えたものが全部、本当とは限らないんだ。」

水鏡が示した西の九尾の祠へ。途中で月見の湯に立ち寄れる。

### 6. 九尾の祠 — 白狐の使い

- 白狐の使い「よく来たね、緋月。人と鬼の契りが憎しみを鎮めたとき、誰かの名も、帰る場所も、守ると誓った約束も……人々は忘れた。」
- 緋月「だったら思い出せばいい。全部取り戻して、もう一度やり直せば！」
- 白狐の使い「それができるなら、どれほどよかったか。……お前が忘れたのは誰かの名ではない。お前自身が交わした約束だ。」
- 緋月「わたしの……約束？」
- 白狐の使い「続きを知りたければ、海の向こうへ行くことだ。だが真実は、誰もが望む姿とは限らないよ。」
- 緋月「潮平さんは、相手の名前を忘れても浜で待ってた。わたしも会いに行く。約束を交わした相手がいるんだもの。」

第1章『花の声が消える里』完。緋月が自分の約束を探す旅へ踏み出す。

## 続編への接続

続編の題は『鬼哭の花契り』。この章では古い契りの余波と、緋月が約束を探しに行く決意までを描く。契りの詳しい成り立ち、緋月が約束を交わした相手、黒幕、血統、エンディングは未確定。水鏡の二人や忘れの森で聞く声の正体も、ここでは明かさない。
