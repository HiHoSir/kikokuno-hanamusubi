## 音と視覚効果
- 水上門・鳥居・飛び石・灯籠・蓮・岩岸・遠景・滝・水面の描き直しを、現行の画像寸法と接地位置で採用。素材台帳の `gitBlobSha` は採用画像、`origin` は差し替え前の素材の出典。浅瀬から深場の境界は、水深と透明度を補間し、参道脇の泡の線を描画から外した。
- 音声のメイン設定と切替：`src/game/audio/audio.mjs`。社では既存`prologue-theme.ogg`をBGMに再利用、滝音だけ旧採用の水音`waterfall-loop.m4a`を小音量で重ねる。音声OFF、画面非表示、退出で滝音も停止し、Safariの操作ジェスチャー後に再試行。
- 旧描画器の `SMRender.draw` により、水面の水深変化・光の反射・滝のアニメ・波紋・前後の描き分け・景色のぼかしを維持する。人物描画のみ村と共通の80×112px原寸アトラス（正面・背面・右・左）に拡張し、各キャラクターの地面接点 `(タイル座標+0.5)×32px` を中心に描画・反射・前後関係を判定する。フィールド専用32pxアトラスを社へ流用しない。
- **2026-11-19一時試作（現行仕様ではない）**：カメラを1.4相当に拡大した後で緋月のみ0.52に縮小していた処理を撤廃。実際の社の見た目が承認されていないにもかかわらず、過去のコードを「承認済み」と記録して復元した説明は誤りだった。この一時試作では村・室内・海の入り江と同一の `WORLD_SCENE_ZOOM=0.5` で表示していたが、iPhone実機では画角が小さすぎ、後述のユーザー指定の1.0に変更した。緋月・白妙・社守はすべて**80×112px/コマ原寸**、画面上では**40×56 CSS px/コマ**（画像内の透過余白を除く）。緋月だけ縮小する `game.heroDisplayScale` や描画側の個別倍率引数を削除。接地位置、当たり判定、会話と移動32pxグリッド、景観アセットは維持。
- カメラは768px最大辺のオフスクリーン描画バッファを使うが、解像度から視野倍率を決めない。**現行は実機で選択された社専用1.0の画角**を採用し、他の場所の0.5カメラとは独立させる。マップ自体の大きさ・素材比率は変更しない。
- iPhoneで歩ける検査用URLは `previews/tenyo-scale-review/`。実本編と同じ `walk.mjs` と `render.js` を使う。検査ページだけはセーブ位置の消費・章進行・フィールド退出を防ぐ。**ユーザーによる外観確認まで合格扱いにしない**。
- iPhone Safariでは長押し・指を離す・画面から復帰・縦横表示・BGM復帰に加え、滝の継ぎ目・前景による人物の隠れ方、光／水面／ぼかしが過度に重くないことを重点検査する。

## 人物の「画像枠」と実際の見た目の差（2026-11-19：プレビュー限定）

- iPhoneからの実画面指摘：社を共通カメラ0.5にしたため左右が広く空き、キャラクターと社の見せ方が破綻。さらに3人の画像枠は同じ80×112pxでも、絵として描かれた人物の大きさは同じではなかった。前回の「枠サイズが同じだから人物サイズが一致」は誤判定。
- 本編はレビュー前にさらに変更せず、`previews/tenyo-scale-review/` に**操作できる外観試作**を用意。旧カメラ1.4と中間1.0を切り替えられる。レビュー時に限り、白妙・社守の既存透過アトラスの実絵をnearest-neighborで約2倍に再配置し、脚の接地点(40,106)・1コマ80×112px・4方向3歩行フレームを保持。緋月や背景の画像は変更しない。
- この試作の2倍加工は**まだ採用されたNPCアセットではない**。ゲーム用PNGファイルを上書きしない。画面と歩行をユーザーが確かめてから、ドット密度と相対サイズも含めて正式画像を整える。実機の外観合格前に「元の画角1.4」「NPC約2倍」をゲーム本編へ勝手に適用しない。

- 画面検査では、従来の緋月の**可視の大きさ（0.52相当）＋元の白妙/社守**と、**原寸緋月＋NPCの可視絵を約2倍**する案の2つを切り替える。前者も承認済みとはみなさない。ユーザーが歩いて比較し、採用バランスを決めるまでは、本編側にいずれも適用しない。

## 実機確認で選択された画角・人物比、足元接触の修正（2026-11-19）

- ユーザーのスクリーンショットで **「広めの画角」＋「従来の人物比」** が選択され、その組み合わせを採用するよう指示された。「0.5の全景カメラ」や「NPCを大きく統一」の案を正本にしない。
- 正式画面は `TENYO_APPROVED_CAMERA=1` を使用（社の元画角1.4ではない）。768px中間描画バッファと実際のカメラ倍率は別概念。背景・全NPC・緋月の共通画角を変更し、画像単独の拡大は行わない。
- 「従来の人物比」は**緋月の見える絵だけを従来の52％にしたもの**。原本の80×112px/コマを壊さず、レンダラーへ渡す前に足元(40,106)を固定した透過アトラスを一時再構成する。白妙と社守は正式アトラスをそのまま表示する。キャラクターの見た目サイズと物理的な接触半径を混同しない。
- 門奥の水面（マップx=8〜19, y=4〜7、ただし社守2人の立つ(13,7),(14,7)を除く）は浅瀬の色があるため歩行可能になっていたが、**遠景の装飾エリア**であるためデータ正本の`terrainBlocks`に追加し歩行不可とした。門の手前の浅瀬・踏み石は変更しない。
- 社の移動だけを0.25セル（8px）刻みにし、元の32px/156msの速度を維持。足元半径8pxと、NPCの足元半径10pxを使って接触し、壁・深水面・灯籠などの既存ブロックは実32pxセル矩形との距離で判定する。以前の「人が小さく描かれていても周囲の32pxセル全域が見えない壁」の状態を解消。歩行、会話、セーブ復元および最南端の出口で、タイル小数座標を保持する。
- `previews/tenyo-scale-review/` は**選択設定を初期状態**にして、本編と共通の描画／歩行コードを使用。操作可能な「判定を表示」ボタンでは、赤＝ブロックしたセル、黄＝NPCの接触距離、青緑＝緋月の足元半径を表示。検査ページの画角比較ボタンは残すが、ユーザーが承認した初期状態を本編に反映した。
- 変更対象は社の描画条件・足元衝突・社の背景水域だけ。フィールド、鬼灯村、海の入り江、社の本体画像、原本NPC画像・音楽・会話・他章のデータは変更しない。実機の当たり判定の合格は、GitHub Actionsの成功とは区別する。
