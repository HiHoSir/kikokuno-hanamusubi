# 天妖の社 — 本編実装

## 正本
- 本編入口：`src/game/tenyo/index.html`（プレビュー専用ではない）
- 実行コード：`src/game/tenyo/walk.mjs`。ゲームのコントローラー・会話・音声は既存共通モジュールを使用
- マップ：`data/maps/tenyo-sanctuary/scene.json`。48×32マス、1マス32px、4方向歩行、入口とNPCの座標・通行判定を同じJSONで管理
- グラフィック：`assets/tenyo/{background,shrine,torii,forest}.webp`。1536×1024の採用済み元レイヤーを再利用し、Canvasの新規手描き背景で代用しない
- NPC：`assets/characters/npc/{shirotae-walk-4dir-32,shrine-guardian-walk-4dir-32}.png`、主人公は既存`assets/characters/hizuki/walk-sd-32.png`
- 採用台帳：`assets/manifest.json` に6点の旧リポジトリ・固定コミット・旧パスを記録

画像・通行判定は旧`HiHoSir/yaksha-hanamusubi`の固定コミット`26136fef4e73bcea60a73edf4e02cd252b3976d0`から移設。素材は新リポジトリの配布物に含む。画像と格子を分けて複製管理せず、`scene.json`を唯一の衝突正本とする。

## プレイヤーが辿る本編ルート
1. `/` の「はじめから」→オープニング→鬼灯村。里長の会話を最後まで聞くと、既存保存キー`kikokuno-hanamusubi-chapter-one`が`shrine`へ進み、目標が更新される。
2. 鬼灯村の南口から`src/field/`に入り、フィールドの天妖の社ランドマークが定義した接触マス（20,43／21,43）へ歩くと`src/game/tenyo/`へ遷移。既存のフィールド物体・通行規則は変更しない。
3. 天妖の社の南側（24,29）へ入場。歩けるマスとNPC占有マス以外は通行不可。白妙（24,9）や社守に正面を向けてAを押す。会話は旧ゲームと同じ文字送り、▼、A/B操作。
4. `shrine`の状態で白妙の話を**最後まで**読むと`cove`へ一方向に進む。次の目標「海の入り江で潮平を探そう」が村への再入場後も維持される。里長の会話をもう一度読んでもイベントを巻き戻さない。
5. 南端の通行可能マス（31行、21〜26列）へ歩くとフィールドへ退出。進入直前に保存したフィールド座標が安全な場合はそこへ戻し、破損・初回直接アクセス時は社周辺の安全なマスを探す。往復時に即再入場するループを避ける。
6. 里長の話を聞く前に天妖の社へ来た場合は、白妙から結び札を預かってくるよう案内され、進行フラグは変更されない。

## サウンドと操作
- `data-bgm="prologue"` で既存の採用済みBGMを再利用し、音声ON/OFF、iOSオーディオのアンロック、復帰処理は `src/game/audio/` の共通実装に任せる。
- 画面は100dvh、タッチ選択防止、共通D-pad、A/B、セーフエリア、縦横の画面向きに対応。会話中は移動しない。
- カメラはマップ境界でクランプし、世界の外を映さない。背景・社殿を後方に合成し、人物を足元Y順に描画、鳥居と森の既存透明レイヤーを前景に重ねる。
