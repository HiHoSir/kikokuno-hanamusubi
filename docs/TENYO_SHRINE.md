# 天妖の社 — 水上聖域の採用版（本編）

## 採用経緯と正本
旧リポジトリ `HiHoSir/yaksha-hanamusubi` で制作した**天妖の社・水上聖域**（β16.1.69〜16.1.70 相当）を採用する。新リポジトリの最初の移植で採用してしまった `assets/maps/tenyo/`（48×32マス、1536×1024レイヤー、森の社）は**別版であり不採用**。その4レイヤーの複製は削除済み。旧リポジトリ上のファイルは消さない。

- 出典の固定コミット：`26136fef4e73bcea60a73edf4e02cd252b3976d0`
- 原マップ：`assets/settlement-editor/maps/tenyo-sanctuary-water-v5.json`
- 本編マップ正本：`data/maps/tenyo-sanctuary/scene.json`。**28列×25行、32px/セル**、水面700セル（深場314・中間150・浅瀬236）、物体78件、地形衝突と通行可能セルを含む。
- 描画器の正本：`src/game/tenyo/rendering/{catalog,autotile,model,render}.js`。水面・泡・波紋・滝、遠景・光源・反射・大気感・被写界深度を、旧採用エンジンの動作に基づいて描画。新たなCanvas図形だけで簡略化しない。
- 実ゲームの入口・操作：`src/game/tenyo/index.html` と `walk.mjs`。旧採用エンジンを読み込み、共通D-pad、A/B、会話、進行フラグ、サウンドと接続する。専用検査画面へ遷移させない。
- 必要な画像：`assets/tenyo/` に採用済みの門・鳥居・踏み石・蓮・岩の小島・灯籠・森と岩のフレーム・遠景・滝・11枚の透明水面群・波紋。全点 `assets/manifest.json` に個別登録、旧出典を記録。水音は `assets/tenyo/waterfall-loop.m4a`。
- キャラクター：`assets/characters/hizuki/walk-sd-32.png`、`assets/characters/npc/shirotae-walk-4dir-32.png`、`shrine-guardian-walk-4dir-32.png`。すでに採用したNPCアトラスは再利用する。物体の足元基準と独立衝突を維持。

## フィールド往復とイベント
1. タイトル→オープニング→鬼灯村→里長との会話。章フラグ `kikokuno-hanamusubi-chapter-one` は `chief` → `shrine`。従来のデータを消さない。
2. 鬼灯村の南口からフィールドへ。旧フィールドが持つ社ランドマークの接触マス（20,43／21,43）に歩いて入場。フィールドの地形・衝突・描画カメラはこの移植では変更しない。
3. 社では北向きに**(13,23)** から開始。元マップの最南端(24行)を出口として維持し、通行可能マスの(12〜15,24)に踏み込んだらフィールドへ戻る。再入場ループ防止のためフィールド側の安全位置へ復帰。
4. 白妙は **(12,8)**、社守2人は **(13,7)、(14,7)**。各人のセルは占有し、隣接する空きマスから正面を向けてAで会話。章フラグが `chief` の場合は里長から結び札を預かるよう促す。
5. `shrine` の状態で白妙の会話を最終行まで読むと `cove` に進み、次の目標「海の入り江で潮平を探そう」を表示。村へ戻っても進捗は戻さない。海の入り江・潮平の個別イベントと戦闘はまだ未実装。
6. 会話UIは `src/game/village/dialogue.mjs`、物語の状態は `src/game/story/chapter-one.mjs` を共有し、決定音／台詞の文字送りは既存SEで再生。

## 音と視覚効果
- 音声のメイン設定と切替：`src/game/audio/audio.mjs`。社では既存`prologue-theme.ogg`をBGMに再利用、滝音だけ旧採用の水音`waterfall-loop.m4a`を小音量で重ねる。音声OFF、画面非表示、退出で滝音も停止し、Safariの操作ジェスチャー後に再試行。
- 旧描画器の`SMRender.draw` により、水面の水深変化・光の反射・滝のアニメ・波紋・前後の描き分け・景色のぼかしを維持する。ヒヅキの正面・背面・左右は既存32pxアトラスで描画。
- iPhone Safariでは長押し・指を離す・画面から復帰・縦横表示・BGM復帰に加え、滝の継ぎ目・前景による人物の隠れ方、光／水面／ぼかしが過度に重くないことを重点検査する。
