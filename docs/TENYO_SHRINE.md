1. タイトル→オープニング→鬼灯村→里長との会話。章フラグ `kikokuno-hanamusubi-chapter-one` は `chief` → `shrine`。従来のデータを消さない。
2. 鬼灯村の南口からフィールドへ。旧フィールドが持つ社ランドマークの接触マス（20,43／21,43）に歩いて入場。フィールドの地形・衝突・描画カメラはこの移植では変更しない。
3. 社では北向きに**(13,23)** から開始。元マップの最南端(24行)を出口として維持し、通行可能マスの(12〜15,24)に踏み込んだらフィールドへ戻る。再入場ループ防止のためフィールド側の安全位置へ復帰。
4. 白妙は **(12,8)**、社守2人は **(13,7)、(14,7)**。各人のセルは占有し、隣接する空きマスから正面を向けてAで会話。章フラグが `chief` の場合は里長から結び札を預かるよう促す。

## 音と視覚効果
- 水上門・鳥居・飛び石・灯籠・蓮・岩岸・遠景・滝・水面の描き直しを、現行の画像寸法と接地位置で採用。素材台帳の `gitBlobSha` は採用画像、`origin` は差し替え前の素材の出典。浅瀬から深場の境界は、水深と透明度を補間し、参道脇の泡の線を描画から外した。
- 音声のメイン設定と切替：`src/game/audio/audio.mjs`。社では既存`prologue-theme.ogg`をBGMに再利用、滝音だけ旧採用の水音`waterfall-loop.m4a`を小音量で重ねる。音声OFF、画面非表示、退出で滝音も停止し、Safariの操作ジェスチャー後に再試行。
- 旧描画器の `SMRender.draw` により、水面の水深変化・光の反射・滝のアニメ・波紋・前後の描き分け・景色のぼかしを維持する。人物描画のみ村と共通の80×112px原寸アトラス（正面・背面・右・左）に拡張し、各キャラクターの地面接点 `(タイル座標+0.5)×32px` を中心に描画・反射・前後関係を判定する。フィールド専用32pxアトラスを社へ流用しない。
- 2026-11-12実機スクリーンショットで**緋月のみ社殿・白妙より著しく大きい**ことを確認。80×112pxは元の歩行アトラスの1コマサイズであり、社内での実表示ピクセル数ではない。`scene.json` の `game.heroDisplayScale=0.52` を本編レンダラーへ渡し、**緋月の描画のみ52%**とする。白妙・社守は従来サイズのまま。同じフレーム座標80×112を参照し、縮尺が変わっても**接地アンカー(40,106)、会話・移動32px格子、衝突・遮蔽・影の接地点は変えない**。拡大率と画像原本の寸法を混同しない。
- iPhone Safariでは長押し・指を離す・画面から復帰・縦横表示・BGM復帰に加え、滝の継ぎ目・前景による人物の隠れ方、光／水面／ぼかしが過度に重くないことを重点検査する。
