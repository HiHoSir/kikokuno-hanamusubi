# 天妖の社・新スプライト試作 v1（iPhone目視待ち）

## 対象と参考
『天外魔境ZERO』SFCの神社・石段・鳥居・滝マップを、**レイヤーの組み立て方／俯瞰角／密度／柱の接地位置**の参考とした。元作品のドット絵やマップをコピー・流用していない。生成したオリジナル原画から透過切り出し、減色して1:1のPNGアトラスに組んだ。

参考一覧: https://www.spriters-resource.com/snes/tengaimakyouzerofareastofedenzerojpn/

## 作成した新規透過アトラス
- `assets/tenyo-rebuild-v1/original-atlas.png` : 320×224px, indexed-color PNG（24色程度、RGBA前提の画面拡大なし）
- `sanctuary_fall_v2`: `[0,0,128,160]`。岩付き滝（原寸）
- `tenyo_water_gate`: `[128,0,192,128]`。水上門（左右柵／中央開口）
- `torii_gate_v2`: `[128,128,128,96]`。鳥居
- `rock_island_lantern_base`: `[0,160,96,64]`。岩島
- `tenyo_stone_lantern`: `[96,160,32,64]`。石灯籠
- 岩島の左右は今は同じ新しい原画を共有。左右の別絵化は未承認なので次段階。

元の `assets/tenyo/`、原本のヒヅキ・NPC、森の背景、地形、水面マップ、会話、BGMは編集しない。ゲーム本編の素材はまだ旧画像のまま。

## 描画の組み直し
**画像全体を人物の手前に持ち上げない。** 試作では新スプライト本体を人物より後ろに配置し、足元の小さい帯だけを各人物の描画直後に、近傍の人物へ限定して重ねる。この前景帯は接触用の障害物ではなく、歩行判定に影響しない。プレビュー以外では従来のレンダリング順を完全維持。

## 確定ルール
- 社守2名の間だけは続編まで封鎖。左右の浅瀬から門を迂回して北側へ行ける。
- 滝周辺の歩行を遮蔽問題の回避で禁止しない。
- 32pxグリッド移動禁止は**フィールドのみ**。社は連続ワールドpx移動。
- 採用済みの画角1.0、従来の人物比、マップサイズ28×25・水面、物語、セーブは不変。
- 外部画像CDN利用なし。すべて本レポジトリ内ファイルに格納。
- 実機の見た目、ドット密度、背景と新規オブジェクトの色合いは**未合格**。CIとユーザー目視を混同しない。

## iPhoneで比較
`/previews/tenyo-scale-review/` の検査設定「新規スプライトを試す」「従来の絵と比較」を利用する。切替はページの再読込（保存データに影響しない）で、滝の重なり位置・門前へショートカットして実際に十字キーで歩く。検査合格後に限り、本編採用案として再評価する。
