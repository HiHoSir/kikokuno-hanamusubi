# 鬼灯村のマップ制作・歩行検査で得た知見

第1作『鬼哭の花結び』の屋外・室内プレビューをもとに、次の村や建物で使う判断基準をまとめる。建物単体の透過素材・軒下・裏回りは[鬼灯村の建物制作・歩行検査](../.agents/skills/build-hozuki-village/SKILL.md)に従う。

## 着手前に揃えるもの

1. 参照絵から使う要素を明記する。俯瞰図は全体像と雰囲気、実ゲームの画面は視点・絵柄の基準として使う。寸法は採用中の歩行キャラを実寸で並べ、入口・段差・家具など、人が使う箇所から決める。
2. ワールドでの物の寸法、ドットの粒、移動・配置の格子、カメラ倍率を分けて記録する。鬼灯村の検査例では緋月のコマは80×112pxで、足元はコマ内の (40, 106)、可視高は約100px。絵柄合わせはおおむねワールド4pxの粒、カメラは0.5倍。これらはこの試作で確認した値。新規マップでは現行の移動方式と採用キャラで決める。
3. 道の接続、入口と退出先、家具や幹の接地面、手前に重ねる絵を先に定義する。素材は原寸で描き、縮尺が合わない素材は入出力寸法を見直す。見える範囲はシーン全体のカメラで調整する。

## 屋外で手戻りを減らす

| 症状 | 制作時の判断と確認 |
|---|---|
| 木・鐘撞堂・草地などがそれぞれ違う解像度に見える | 緋月と建物が入る同じゲーム画面で、輪郭の段差、陰影の面積、瓦・葉・石の細かさ、光源と色を見比べる。素材の寸法を合わせたあとも、全景と縦画面の両方で絵柄を確認する。 |
| 道がガタつく、橋の出入口で幅が変わる | 必要な動線を中心線と幅で設計し、直線区間の端や交差点を確認する。橋は板の見える幅、足元が通れる幅、両岸の道を照合する。中央の往復と両脇で止まることを実際に検査する。 |
| 川が静止した模様に見える | 岸の輪郭・橋・岸の装飾を分け、水面の波を一方向へ動かす。中央を岸寄りより速くし、同じ粒で波を描く。波の描画順を橋より下に置き、橋の両側と動きを減らす設定で確認する。 |
| 枝葉が屋根や入口にかかる | 透明な余白を含む画像全体と、実際の枝葉・屋根の輪郭を分けて比較する。正面を隠す場合は木を移し、描画原点・幹の接地・奥行き・通行判定を同じ量だけ動かす。移動先と元の位置で歩き、道や畑に新しい干渉が出ていないかも見る。 |

配置変更のたびに、修正箇所に加えて、橋の両岸・鐘撞堂の階段・民家の軒下と裏・畑の周囲を一巡する。屋根や枝葉による見た目の遮蔽と、壁や幹による足元の衝突を別々に点検する。木の下を歩く場合は緋月が完全に消える位置がないか確認する。

## 室内を作り、別の建物で使う

- 間取りには床の範囲、出入口、家具の配置、足元の通行判定、奥行き順を持たせる。建物IDと間取りIDの対応は別に置く。茶店・物販店・宿・兵具屋は間取りを再利用できる形とし、民家は農家・家族の民家・仕事場付きの3例を作った。
- 同じ画面で家具と建具を並べてから全室へ展開する。鬼灯村では家具の木色と輪郭を壁・柱・障子・仕切りの基準にした。家具の接地影は足元に限定し、奥行き順と衝突には配置データの接地面を使う。
- 板の間・畳・土間の境目は同じ床面としてつなぐ。畳は縦横の一畳と必要な場所の半畳を部屋ごとに敷く。鬼灯村では4枚の角が一点に集まらない祝儀敷きとし、縁は長辺の内側に置いた。畳や土間の外周に厚い輪郭や落ち影を描くと段差に見える。壁際の影は床材をまたいで続ける。[畳を知る（あおい畳）](https://aoiniigata.com/know/)
- 床板は板幅と長さを変え、隣の列と継ぎ目をずらす。部屋ごとの模様を再描画のたびに変えず、同じ位置で前後比較できるようにする。茶店の客席、宿の帳場と客間、農家の土間と畳の境を並べると、床面の違和感を見つけやすい。
- 屋外の入口から入り、家具の前後や仕切りを回って、入った棟の前へ戻る。単独の室内検査で開く部屋と屋外に対応する建物がある部屋を区別し、建物IDが異なる場合もそれぞれの入口へ復帰することを確かめる。

## 検査と引き継ぎ

| 確認すること | 方法 |
|---|---|
| 見た目と縮尺 | 同じカメラで変更前後を比較する。全景、緋月と入口が並ぶ画面、画面の狭い縦持ちで確認する。 |
| 通行・遮蔽 | 判定表示で足元と衝突の境を見て、屋外の全入口・裏道・橋・階段、全室の出口・家具脇・目的地点を検査する。自動検査に加えて前後の見え方を歩いて確認する。 |
| 配信と実機 | 対象コミットとPagesのHTML・モジュール・変更した素材を照合し、実際に開いて表示・操作を確認する。iPhone Safariでは縦持ちの構図、方向ボタンの長押しと解除、屋内外の往復を確認する。自動検査、公開版ブラウザー、実機、素材採用の結果を個別に記録する。 |
