# 鬼灯村の歩行検査

検査ページ: `previews/village-walk/index.html`。GitHub Pages の `gh-pages` 配信物で、素材の本編採用とは別。Sites版を新しい正本にせず、既存のリポジトリから配信する。

## 表示の修正

- 建物は単体検査ページから取得した原寸PNGを使い、全棟0.5倍の最近傍サンプリングを一度だけ行う。軒は同じ縮小済み建物から切り出して重ね、別々に縮小しない。
- 同じ桜の縮尺違い25枚を廃止。幹の接地位置は維持し、共通素材を使う。緑の木も成木と低木を区別し、それぞれ共通素材を使う。
- カメラは端末の物理ピクセルの整数倍で描画。固定1.2倍は希望値とし、ドットが均等になる実倍率に丸める。世界座標の移動速度は変えない。
- 道は `scene.json` の線・幅を原寸でタイル化。16px単位で輪郭を丸めない。既存の道テクスチャを原寸反復し、斜辺をタイル内に保持する。
- 川・畑・橋は別レイヤー。元の素材の描き込み密度や画風の差まで統一済みとは扱わない。
