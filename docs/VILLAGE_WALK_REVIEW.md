# 鬼灯村の歩行検査

既存の `previews/village-walk/` をGitHub Pagesから配信する。ここでの寸法は歩行版の検査基準で、本編への素材採用とは別。

## 緋月を基準とした縮尺

緋月は既存の80×112px歩行コマ、足元(40,106)。全12コマの可視高97〜100pxを確認し、約100pxを1人分の高さとする。配置時に個別の倍率で合わせず、この基準で用意したPNGをワールドに原寸で描く。歩行検査のカメラはシーン全体を0.5倍で表示する。

| 素材 | ゲーム用PNG・通路の寸法 | 縮尺の判断 |
|---|---:|---|
| 緋月 | コマ80×112、可視高97〜100 | 既存PNG・足元・歩行速度を保持 |
| 藍瓦・茅葺きの民家 | 360×373、390×357 | 入口の柱間62・68px、見かけの高さ92・93px。緋月の可視幅54〜58pxと比較し、軒と踏み石の位置を合わせる |
| 茶店・宿 | 420×410、512×385 | 入口の柱間66・64px、見かけの高さ115・95px。緋月が入口に立てる寸法で、用途に応じた建物幅 |
| 鐘撞堂 | 432×440 | 成人人物が立てる軒下と柱間、幅約129pxの階段の通行部分 |
| 桜・緑の成木 | 279×290、246×275 | 緋月の約2.8〜2.9人分の高さ。幹と樹冠を描き直した |
| 低木 | 62×36 | 既存の葉素材を原寸で組み、枝葉が地面近くに広がる茂みに差し替え。株元の半径10pxを判定に使用 |
| 鬼灯 | 40×40、60×50、80×60 | 可視高約34〜45px。静止画と揺れの全コマを同じ寸法で書き出し、接地を揃える |
| 畑の木柵 | 32×30 | 畑の奥辺を32pxごとに接続。接地の4pxに通行判定 |
| 畑の作物 | 葉の可視高14〜27px | 苗14px、葉物21px、背の高い株27px。畝の32pxタイル内で株元を揃える |
| 草・野花・花びら | 草・野花は可視高7〜21px、花びらは1枚数px | 草花は道と畝を避けて草地に配置。花びらは地面と川面に点在 |
| 川岸の石 | 幅14〜32px | 両岸に沿って大小を混ぜ、橋の出入口を空ける |
| 木橋 | 木部112px幅、通行幅104px | 中央の板を1列増設し、両岸の道を同じ通行幅でつなぐ |
| 道・川 | 中央道104px、横道64〜76px、枝道64px、川幅128px | 橋の出入口で中央道が細くならない。横道と枝道で入口・畑を結ぶ |

成木と鐘撞堂は旧素材の画素を拡大したものではなく、既存絵柄と緋月を参照して新しく描いた。成木は上からやや見下ろす視点、左上からの光、太い幹と狭い接地点。鐘撞堂は青瓦・木の柱・青銅鐘・右の撞木・基壇に続く中央階段を継承し、緋月が立てる柱間と軒下を確保した。出力はそれぞれ単独の透過RGBA PNG。

## 村全体のドット表現

同じ画角で緋月と建物のドットを基準にし、草地、土道、作物、川、木橋、柵、樹木、鬼灯、草花、石、花びら、鐘撞堂はワールド4pxの粒で書き出す。元の絵の色を4pxごとに拾う。緋月・民家・茶店・宿は基準として入力元のPNGを使う。鐘撞堂は瓦、柱、鐘、石積み、階段を同じ粒で描き、透過輪郭は元の形を使う。川と道の外形は元の座標で描き、木橋の板目は4pxの粒で残す。鬼灯は4pxごとに葉と実を動かし、株元を固定する。

書出しの入力はコミット `eda7611fd6099a932772f7f3e7b7a1cf18012533` の `previews/village-walk/map/`。別のディレクトリへ展開した入力を `tools/export-village-walk-art.py <入力map> previews/village-walk/map` に渡し、`tools/build-village-walk-ground.py` で地面を組み立てる。PNGの寸法、描画アンカー、道の形、足元の判定は同じ座標を使う。南東の柵・作物・鬼灯・宿が見える位置、北側の鐘撞堂と桜、橋と川岸で、同じ画角の変更前後を比べてから村全体を確認する。

川は元のタイルの透過形状で岸を描く。水面には長さと間隔の異なる4px単位の波を置き、西から東へ動かす。中央の波は岸寄りより速い。橋と川岸の装飾は波の上に重ねる。端末で「視差効果を減らす」が有効な場合は、波を静止表示する。`?focus=bridge` で流れと橋の前後関係を確認できる。

## 配置・通行

- 村は2400×2240px。承認済みの俯瞰イラストは雰囲気と位置関係の参考にし、寸法は素材と通路の実測で決める。道路は水平・垂直、川は東西、橋と鐘撞堂は中央南北道で結ぶ。
- 新しい鐘撞堂の左右に余地を取るため、北西の民家2棟と茶店の位置・入口・枝道を調整した。北東の畑の一画は、縁と鬼灯を付けたまま30px移動。橋の南東の藍瓦の民家は入口と判定ごと24px東・12px南に移した。家の鬼灯18株は、各家の画像原点からの相対位置で保持する。村全体の鬼灯68株は枝道と畝の株元を空けて配置する。
- 鐘撞堂の画像左上(924,120)、階段の接地(1140,560)、確認位置(1140,456)。中央階段と基壇の正面を通行可。両側の石積み、裏側と柱の領域は衝突で止める。
- 桜16本・緑の成木6本・低木9株。混み合っていた桜を間引き、樹冠を中央道の外へ移した。植栽は幹や根元の接地だけを衝突にする。入口・畑・橋を隠さない位置に置く。樹冠が背後の緋月の頭に重なるときだけ、その木を薄く描く。
- 南西の藍瓦の民家を含め、村全体で成木と建物の透過輪郭を照合し、屋根や軒と交差していた木を移動した。描画位置・幹の接地・描画順・通行判定を同じ移動量で揃える。樹冠が道路にかかる箇所でも幹は草地に置き、入口と橋の歩行経路を確保する。
- 南東は茅葺きの民家と宿の間に道と草地の間隔を確保し、宿の屋根が道にかからない配置にした。隣接する二つの畑は各4列×4畝から5列×5畝へ広げ、作物・柵・鬼灯をそれぞれの畑に揃えた。北東の道は家の間から畑の脇へつなぐ。川沿いの桜を分散し、鐘撞堂の基壇前と橋の南の並木に余白を取った。
- `tools/build-village-walk-ground.py` がsceneの配置から地面と衝突PNGを作る。通常開始とリセットは橋の南。`?focus=belltower` で鐘撞堂の正面を確認できる。

## 検査

現行の歩行版が参照する19枚のPNGを対象に、フレーム、タイル、地面装飾の切り出しと配置を確認した。

| 対象 | 検査範囲 |
|---|---|
| 緋月 | 前後左右の静止・歩行12コマ。足元と可視範囲 |
| 建物・植栽・柵 | 民家2種・茶店・宿・鐘撞堂、桜・緑の成木・低木、木柵。入口、軒の切り出し、透過、全配置 |
| 鬼灯 | 3種類・68株。各静止画と揺れ8コマの全27コマで色、接地、切れを確認 |
| 地面・橋 | 草地1種、道257種、作物3種、川5種、木橋9種の計275タイル。配置、反復、境界 |
| 地面装飾 | 草・野花、川岸の石、花びらの61種・510配置。寸法、透過、描画範囲 |
| 通行判定 | 衝突PNG、道・建物入口・畑・橋との対応 |

- `node --test tests/village-walk-render.test.mjs`: 18件。成木・低木・鐘撞堂の原寸、足元、個別拡縮なし、軒と入口、鬼灯、樹冠遮蔽、カメラと直線道路、橋と中央道の接続、南東の建物と道の間隔、畑と柵の接地、川の流れる方向・速度差・4px単位の描画を検査。
- 衝突PNGと半径8pxの足元で、全18地点への到達、全道路中心線、鐘撞堂の階段と基壇、橋の中央と両脇を確認。9棟と鐘撞堂の裏・側面で12歩行コマを調べ、どのコマも完全には隠れない。道路上の樹冠遮蔽も全コマで検査。
- 配置変更後は全景を組み直し、橋の両岸、北西の民家と鐘撞堂、北東の茶店・畑、南西の民家・畑、南東の民家・宿・畑を一巡する。全景で道の端・植栽の密度・川の見え方を確認し、縦画面では緋月と入口・小物が同じ画面に入ったときの比率と足元を確認する。iPhone実機Safariは未確認。
- 配信ブランチの既存のリポジトリ検査は、既存 `previews/` パスを不許可と判定する。規則を緩めていないため、ブランチ全体の `npm test` 通過とは扱わない。

## 室内の歩行検査

民家・茶店・宿の入口で「中に入る」を表示する。室内の南の敷居まで下に歩くか「外へ出る」を押すと、入った建物の入口に戻る。室内の選択欄から、村に建物がない物販店と兵具屋も検査できる。

| 間取り | 使い方 |
|---|---|
| 茶店 | 茶棚・給仕台・畳の客席 |
| 物販店 | 商品棚2面・反物とそろばんのある売り台 |
| 宿 | 帳場と客間を仕切り、左右2箇所の通路で結ぶ |
| 兵具屋 | 刀・槍の陳列棚と試し見用の台 |
| 農家 | 土間側の炊事・収穫物と、囲炉裏のある畳の間 |
| 家族の民家 | 卓と二組の布団のある居間 |
| 仕事場のある民家 | 木工台と道具棚、畳の寝所 |

間取りは `previews/village-interiors/rooms.mjs` に置き、建物IDと間取りIDの対応は `villageRooms` に定義する。同じ間取りを使う建物は対応を追加する。窓・畳・仕切り・家具は個別座標を持つ。家具の透過画像と床の占有矩形は別に定義し、緋月の足元と占有面の奥行きで前後を描き分ける。緋月の原寸80×112px歩行コマ、0.5倍のカメラ、足元半径8pxは屋外と共通。

室内用家具は新規の16点を透過アトラス `furniture.png` にまとめた。生成原画のSHA-256は `f1a918c82c49508ca05bc0c1b6233de41d1e4f294e676332750e9948853e6603` と `9227a5d3e212a7ec27d6a37977ef88598f2676f260b1b835037a5e0830f528ec`。各セルを透過輪郭で切り出し、最終寸法の1/4で48色まで減色後、最近傍で4倍にして4px単位のドットに揃えた。床・畳・建具は座標から描く。

壁・柱・障子・仕切りの輪郭と木部は家具アトラスの木色を参照し、床板と畳の目も含めてワールド4px単位で描く。家具と仕切りの接地影は床に描き、家具の配置と足元の判定は間取りデータを使う。

`tests/village-interiors.test.mjs` は7間取りの入口・出口・各目的地点への経路、村の9入口との対応と戻り先を検査する。
