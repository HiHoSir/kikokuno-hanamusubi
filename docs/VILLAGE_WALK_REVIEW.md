# 鬼灯村の歩行検査

既存の `previews/village-walk/` をGitHub Pagesから配信する。ここでの寸法は歩行版の検査基準で、本編への素材採用とは別。

## 緋月を基準とした縮尺

緋月は既存の80×112px歩行コマ、足元(40,106)。全12コマの可視高97〜100pxを確認し、約100pxを1人分の高さとする。配置時に個別の倍率で合わせず、この基準で用意したPNGをワールドに原寸で描く。カメラ0.75倍はシーン全体に適用する。

| 素材 | ゲーム用PNG・通路の寸法 | 縮尺の判断 |
|---|---:|---|
| 緋月 | コマ80×112、可視高97〜100 | 既存PNG・足元・歩行速度を保持 |
| 藍瓦・茅葺きの民家 | 360×373、390×357 | 原寸の緋月を使用した単体建物検査の素材を再利用 |
| 茶店・宿 | 420×410、512×385 | 同じ緋月で入口と軒を検査。用途に応じた建物幅 |
| 鐘撞堂 | 432×440 | 成人人物が立てる軒下と柱間、幅約129pxの階段の通行部分 |
| 桜・緑の成木 | 279×290、246×275 | 緋月の約2.8〜2.9人分の高さ。幹と樹冠を描き直した |
| 低木 | 56×56 | 背の低い植栽として既存素材を使用 |
| 鬼灯 | 32×32、48×40、64×48 | 可視高およそ27〜36pxの草丈。成木と区別して扱う |
| 畑縁 | 28×15 | 畑の低い木の縁。人の背丈に近い柵ではない |
| 橋 | 96px幅、通行幅80px | 緋月が通れる一人分の幅。板は原寸反復 |

成木と鐘撞堂は旧素材の画素を拡大したものではなく、既存絵柄と緋月を参照して新しく描いた。成木は上からやや見下ろす視点、左上からの光、太い幹と狭い接地点。鐘撞堂は青瓦・木の柱・青銅鐘・右の撞木・基壇に続く中央階段を継承し、緋月が立てる柱間と軒下を確保した。出力はそれぞれ単独の透過RGBA PNG。

原画のアルファ20超の外接範囲を切り出し、縦横比を維持した最近傍で最終寸法に書き出した。実行時に素材を再サンプリングする個別倍率は持たない。採用済みの `assets/` は変更していない。

## 配置・通行

- 村は2400×2240px。承認済みの俯瞰イラストは雰囲気と位置関係の参考にし、寸法は素材と通路の実測で決める。道路は水平・垂直、川は東西、橋と鐘撞堂は中央南北道で結ぶ。
- 新しい鐘撞堂の左右に余地を取るため、北西の民家2棟と茶店の位置・入口・枝道を調整した。北東の畑の一画は、縁と鬼灯を付けたまま30px移動。家の鬼灯18株は、各家の画像原点からの相対位置で保持する。
- 鐘撞堂の画像左上(924,120)、階段の接地(1140,560)、確認位置(1140,456)。中央階段と基壇の正面を通行可。両側の石積み、裏側と柱の領域は衝突で止める。
- 桜21本・緑の成木6本・低木9株。植栽は幹や根元の接地だけを衝突にする。入口・畑・橋を隠さない位置に置く。樹冠が背後の緋月の頭に重なるときだけ、その木を薄く描く。
- `tools/build-village-walk-ground.py` がsceneの配置から地面と衝突PNGを作る。通常開始とリセットは橋の南。`?focus=belltower` で鐘撞堂の正面を確認できる。

## 検査

- `node --test tests/village-walk-render.test.mjs`: 11件。成木・鐘撞堂の原寸、足元、個別拡縮なし、軒と入口、鬼灯、樹冠遮蔽、カメラと直線道路を検査。
- 衝突PNGと半径8pxの足元で、全18地点への到達、全道路中心線、鐘撞堂の階段と基壇、橋の中央と両脇を確認。9棟と鐘撞堂の裏・側面8,056地点で12歩行コマを調べ、どのコマも完全には隠れない。道路上の樹冠遮蔽も全コマで検査。
- クラウドChromeで縮尺と配置を目視確認。iPhone実機Safariは未確認。
- 配信ブランチの既存のリポジトリ検査は、既存 `previews/` パスを不許可と判定する。規則を緩めていないため、ブランチ全体の `npm test` 通過とは扱わない。
