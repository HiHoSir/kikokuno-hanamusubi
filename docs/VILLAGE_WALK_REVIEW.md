# 鬼灯村の歩行検査

検査ページ: `previews/village-walk/index.html`。GitHub Pages の `gh-pages` 配信物で、素材の本編採用とは別。Sites版を新しい正本にせず、既存のリポジトリから配信する。

## 表示の修正

- 建物は単体検査ページから取得した原寸PNGを使い、全棟0.5倍の最近傍サンプリングを一度だけ行う。軒は同じ縮小済み建物から切り出して重ね、別々に縮小しない。
- 同じ桜の縮尺違い25枚を廃止。幹の接地位置は維持し、共通素材を使う。緑の木も成木と低木を区別し、それぞれ共通素材を使う。
- カメラはユーザー指定の1.0倍を固定し、端末の画素密度では変更しない。画面全体の拡大は行わず、素材の設定寸法と画面内のCSSピクセルを1対1にする。世界座標の移動速度は変えない。
- 道は `scene.json` の線・幅を原寸でタイル化。16px単位で輪郭を丸めない。既存の道テクスチャを原寸反復し、斜辺をタイル内に保持する。
- 川・畑・橋は別レイヤー。元の素材の描き込み密度や画風の差まで統一済みとは扱わない。

## 鐘撞堂と道の差し替え

- 添付された完成見本の鐘撞堂（屋根の幅約311px）と、その左の藍瓦の家（約190px）の比率は約1.64。現在の藍瓦の家は180pxなので、鐘撞堂の新素材は幅300pxに設定。これは目標画像との相対比から決めた表示寸法。
- `map/belltower.png`: 300×330 RGBA。生成した原画1254×1254のアルファ20超の範囲(107,57)-(1147,1202)を切り出し、最近傍で一度だけ縮小。旧鐘撞堂の拡大ではない。中央下段の接地は(800,480)、画像左上(650,150)。
- 基壇と階段は新しい鐘撞堂の画像に含まれるため、旧 `bell-platform` / `bell-stairs` 層と旧鐘撞堂画像は削除。中央の階段は通行可、石積み左右は通行不可。鐘撞堂の目印は階段上の(800,426)。
- `map/path-soil.png`: 生成した土と小石の原画を256×256でゲーム用に用意。既存経路・道幅に沿って貼り、細かな輪郭と草の接点をタイル内に持つ。道幅を32px格子へ丸めていない。
- `?focus=belltower` で鐘撞堂の階段から検査できる。通常の開始位置とリセットは橋の南。
- 画面倍率はユーザー指定の1.0倍。

検査: 5件の表示回帰テスト、足元半径4pxで15目印への到達、階段中央の通行と石積み左右での停止を確認。クラウドChromeで新しい鐘撞堂・基壇・階段・道の描画を確認。草・花びら・低木の密度と村全体の画風は見本との差が残る。
