# 鬼灯村の歩行検査

`previews/village-walk/` を既存GitHub Pagesから配信する。本編の素材採用とは別の歩行検査。

## 原寸描画と配置

ユーザー指定: 建物を含む画像を拡大縮小しない。承認された俯瞰イラストは村の雰囲気と位置関係の参考であり、画像の寸法や構図を固定条件にしない。道は水平・垂直。

- 建物・鐘撞堂・木・鬼灯と緋月をすべて原寸描画する。画像の作り直しや、縮小PNGへの置き換えで倍率を隠す方法は使わない。既存のPNGは無加工で保持。
- 建物は藍瓦360×373、茅葺390×357、茶店420×410、宿512×385。実行時の縮小Canvasと `sprite.scale` を撤去。軒は同じ原寸画像の元の矩形から等倍で重ねる。
- 緋月は既存80×112の歩行コマを原寸描画し、足元(40,106)。村で残っていた0.5倍処理も撤去し、単体建物検査と同じ原寸同士で組み合わせる。足元半径は原寸検査の8px。画像データ・外見・歩行コマ・速度は変更していない。
- カメラは1.0倍、端末のDPRで倍率を変えない。
- 同じ桜の個体別拡縮をしない。鐘撞堂は既存の300×330px素材をそのまま使用。新しい画像生成は行っていない。
- 各家の左右の鬼灯18株は `anchor: {kind:'building',id,offset}` で所属棟と原寸の相対位置を記録。地面構築時に建物座標から位置と描画順を再計算する。入口中央を空け、根元を基礎の接地位置へ揃える。
- その他の鬼灯は畑の左右や道から離れた地面へ配置し直す。合計68株を画面範囲内に収める。
- 原寸の家、左右の裏道、畑と直線道路が重ならないよう配置し直し、範囲を2400×2240pxとした。川は東西、橋と鐘撞堂を南北道で結ぶ。道路17本は水平・垂直の線分だけ。
- 橋は96px、通行幅80px。既存板を原寸反復。土道の256pxテクスチャも原寸反復。32pxは地面の内部分割であり、素材や道路幅の必須格子ではない。
- `tools/build-village-walk-ground.py` が同じscene定義から地面と衝突PNGを構築する。配置・画像のURLに更新識別子を付け、旧キャッシュとの混在を避ける。

通常の開始位置・リセットは橋の南。`?focus=house-northwest-tile` など目印IDで各地点から検査可能。

## 確認範囲

- `node --test tests/village-walk-render.test.mjs`: 8件。画像寸法そのままの描画、家との鬼灯アンカー、共通素材、カメラ1.0、直線道路、鐘撞堂の基壇と裏側接触を検査。
- 衝突PNGを足元半径8pxで収縮し、全18目印（9棟、7畑、鐘撞堂、橋）への到達と、道路中心線の全画素通行を確認。
- 家の左右・裏回り、全12歩行コマの頭の残り、原寸の軒と入口を確認。家屋と鐘撞堂の通行可能な裏・横7,947地点で12コマ全ての頭が残り、全9棟の軒が全コマと172〜216画素重なる。橋中央は通行し、橋の両脇は水面で止まる。
- クラウドChromeで原寸表示と家・鬼灯の重なりを目視確認。iPhone実機Safariは未確認。
- mainの既存検査は21件と素材台帳検査が通過。配信ブランチの古い `tools/check-repository.mjs` は、既存の洞窟・村の `previews/` 12ファイルと村検査を不許可と判定する。ブランチ全体の `npm test` 通過とは扱わず、規則も緩和していない。

素材そのものの描き込み密度や画風の差は、描画倍率で補正済みとは扱わない。必要な素材修正は原寸を前提に別途検査する。
