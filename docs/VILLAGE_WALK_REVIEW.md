# 鬼灯村の歩行検査

`previews/village-walk/` を既存GitHub Pagesから配信する。本編の素材採用とは別の歩行検査。

## 今回の配置基準

承認された「桜咲く鬼灯村と川辺の鐘楼」の俯瞰イラストを、村全体の雰囲気と位置関係の参考にする。画像の画素寸法や構図をそのまま再現する仕様ではない。

- 緋月は80×112の歩行コマを0.5倍、表示高約50pxのまま。画面倍率はユーザー指定の1.0倍。DPRで倍率を変更しない。
- 家屋は原寸PNGから共通の0.625倍で一度だけ最近傍縮小。戸口の高さは藍瓦57.5px、茅葺58.1px、茶店71.9px、宿59.4px。軒は同じ縮小済み画像から切り出す。
- 桜は共通の129×120px素材。緑の木も種類ごとに共通素材を使う。個体ごとの拡縮はしない。
- 川は東西、橋と鐘撞堂を中央の南北道で結ぶ。9棟の入口と畑へ水平・垂直の枝道を通す。道路17本はすべて直交折れ線。
- 建物・畑・道の必要寸法から村の範囲を1960×1800pxに設定。土道の256pxテクスチャは原寸反復する。32pxは地面の内部分割単位であり、道路幅や村の必須格子ではない。
- 橋は幅96px、通行幅80px。既存の橋の中央板を原寸で追加し、両側の欄干を保つ。
- 鐘撞堂は生成済みの300×330px RGBA素材を使用。基壇・階段を含む1枚で、追加拡大はしない。画像左上(800,170)、接地(950,500)。中央の階段を通行可能にし、石積み左右と屋根裏を遮る。
- 足元半径は4px。家屋と鐘撞堂の裏側は、緋月の頭が屋根の上に残る接触位置にする。

`tools/build-village-walk-ground.py` がsceneの配置定義から地面・橋・衝突マスクを再構築する。`?focus=belltower` など目印IDで各地点から検査可能。通常開始とリセットは橋の南。配置とPNGにも更新識別子を付け、以前の村のキャッシュとの混在を避ける。

## 確認結果と範囲

- `node --test tests/village-walk-render.test.mjs`: 7件通過。戸口、共通素材、1.0倍、直線道路、鐘撞堂の基壇と裏側の接触位置を確認。
- 実際の衝突PNGを足元半径4pxで収縮し、開始地点から9棟の入口・7つの畑目印・橋・鐘撞堂の全18地点へ到達可能。道路の中心線は全画素通行可能。橋の中央は通行、橋の脇の水面は停止。
- 家屋9棟の裏側の左・中央・右へ到達できる。全12歩行コマで屋根裏の緋月の可視画素を確認。鐘撞堂の裏・横・角は通行可能な1,623地点を全12コマで調べ、最低141画素の頭部が残る。
- 地面の再構築は同じ入力でscene・地面・衝突PNGが同じバイト列になる。
- クラウドChromeで戸口、直線の道、橋、鐘撞堂と重なりを目視確認。iPhone実機Safariは未確認。
- mainの既存検査は21件と素材台帳検査が通過。配信ブランチの既存テストは19件通過。ただし配信ブランチの古い `tools/check-repository.mjs` は、既存の洞窟・村の `previews/` 12ファイルと村検査を不許可と判定するため、ブランチ全体の `npm test` 通過とは扱わない。規則は緩和していない。

素材の画風、植栽の密度、全景イラストとの雰囲気の差は引き続き調整対象。
