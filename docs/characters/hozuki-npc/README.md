# 鬼灯村 NPC素材 4方向・歩行版

共通店員、畑仕事の村人、村人、年配の村人、子ども、鐘守の6種です。`walk-preview.gif` で4方向の歩行ループを、`preview.png` で4方向の待機絵を確認できます。

茶店 `teahouse`、道具屋 `shop`、宿 `inn`、兵具屋 `armory` は、すべて `npc-walk.json` の `shop-clerk` を参照します。施設ごとの会話や処理は各施設のデータで設定できます。

## スプライトシート

`sprites/` の各透過PNGは240×448 pxです。鬼灯村の緋月と同じ80×112 pxのコマと足元アンカー (40, 106) を使います。正面待機は第1弾の絵と同じです。

| 行番号 | 向き | 0列目 | 1列目 | 2列目 |
| ---: | --- | --- | --- | --- |
| 0 | 前（下） | 待機 | 歩行A | 歩行B |
| 1 | 後ろ（上） | 待機 | 歩行A | 歩行B |
| 2 | 右 | 待機 | 歩行A | 歩行B |
| 3 | 左 | 待機 | 歩行A | 歩行B |

歩行中は進んだ距離に応じて列番号 `1 → 0 → 2 → 0` を繰り返し、停止時は0列目を表示します。シート内のコマ原点は `(列 × 80, 行 × 112)`、マップ上の描画原点は `(足元X − 40, 足元Y − 106)` です。
