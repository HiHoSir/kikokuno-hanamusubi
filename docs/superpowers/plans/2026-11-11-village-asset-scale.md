# 鬼灯村の緋月基準の素材寸法

緋月の現行80×112歩行コマと足元(40,106)を固定する。原寸の可視高約100pxが、建物・樹木・作物・小物の共通基準。カメラ0.75倍は画面全体に適用し、個別描画倍率や旧PNGの拡大では比率を補正しない。

- [x] 合っていない成木（桜120px、緑の成木89px）と旧い小さい緋月向けの鐘撞堂を、緋月に合わせた絵に描き直す。成木の完成高は桜290px・緑275pxを目安、鐘撞堂は高さ約440pxと十分な柱間・軒下・中央階段を確保する。生成原画はゲーム素材の最終寸法に書き出す。
- [x] 単体検査で80×112の緋月と揃えていた民家・茶店・宿は原寸を採用。鬼灯の草丈、低木、作物、低い畑縁、橋の通行幅も同じ基準で確認する。
- [x] 原寸PNGと足元アンカーで配置を再計算。村の範囲は2400×2240、道は縦横のまま。成木は樹冠でなく幹の接地を判定し、家の入口と畑を隠す位置を避ける。鐘撞堂は屋根裏・左右・中央階段と基壇を個別検査。
- [x] 共通寸法・透過・足元・18地点の通行・屋根/樹冠の遮蔽を検査し、既存Pagesの歩行版で確認する。iPhone実機と本編採用は別工程。

対象は `previews/village-walk/map/` の素材と配置、`walk.mjs`、`tests/village-walk-render.test.mjs`、現行検査記録。配信時は最新 `gh-pages` の村以外の更新を保全する。
